# Compliance Notes

The following guarantees are part of the project contract:

- provider supported does not mean provider enabled;
- model known does not mean model enabled;
- capabilities are declared, not guessed;
- MCP is default deny;
- external actions must be traceable;
- multimodal transformations must be explicit pipelines;
- streaming and structured output require real capabilities;
- secrets must not appear in logs, metadata, or errors.
