# Multimodal Context

Context types include text, markdown, code, image, PDF, audio, video, generic
file, MCP resource, and derived context.

Capybara AI does not perform automatic:

- OCR;
- PDF parsing;
- audio transcription;
- video analysis;
- file parsing;
- hidden conversion;
- hidden text fallback.

Pipelines must be explicit, configured, traceable, and documented as derived
context rather than native model support.
