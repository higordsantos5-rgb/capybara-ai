# Capability Registry

The registry stores explicit `ModelCard` entries. It does not infer capabilities.

Core capabilities include:

- `text`;
- `markdown`;
- `code`;
- `image`;
- `pdf`;
- `audio`;
- `video`;
- `file`;
- `mcp_compatible`;
- `streaming`;
- `structured_output`.

Streaming and structured output are capabilities, not universal promises.
